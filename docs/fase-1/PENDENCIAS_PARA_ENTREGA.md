# Pendências acadêmicas e técnicas

## GitHub

A estrutura atual separa Web, Mobile e índice comum. O backlog está nas issues de cada disciplina. Confirmar no AVA se GitHub Issues atende ao quadro exigido; caso seja obrigatório Trello ou outro Kanban, criar o quadro e registrar seu link. Issues não são um GitHub Project visual.

## Relatório Web

- Revisar matrícula, polo, unidade e contato institucional autorizado localmente.
- Confirmar template atual e prazo oficial no AVA; histórico recente menciona tópicos 1–10 até 26/09/2026.
- Atualizar URLs e evidências do Git com o histórico real.
- Consolidar RF/RNF, critérios, MVP, arquitetura e planejamento das sprints.
- Validar regras de reserva, status oficiais, perfis e permissões.
- Corrigir e testar pendências da auditoria antes da integração.

Nenhuma atividade funcional, sprint ou validação institucional é considerada concluída pela organização do GitHub. Pendências Mobile são mantidas no repositório Mobile.
